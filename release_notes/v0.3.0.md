# MFDS v0.3.0

Linux aarch64 및 x86_64용 빌드 패키지를 제공합니다. Debian Bookworm(glibc 2.36)에서 빌드하고 native 회귀 검사를 수행합니다.

패키지는 컴파일된 서버·공유 라이브러리·CLI, GPL Python 연동 모듈 및 지원 파일, 라이선스 고지와 파일별 SHA-256을 포함합니다. C++ 소스나 Git 저장소는 포함하지 않습니다. Python 파일은 해석 실행 및 GPL 소스 제공을 위해 포함합니다. 모든 수정은 MFDS 저장소에서 진행하고 소비자는 릴리즈를 고정해 설치합니다.

검출 알고리즘·프로세스 ABI·라이선스 조건은 그대로입니다. 소스는 이 태그에서 제공됩니다. 패키지 SHA-256은 첨부된 체크섬 파일로 확인하세요.
