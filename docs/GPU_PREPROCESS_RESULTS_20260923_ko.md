# GPU 전처리 옵션 구현·실기기 검증 — 2026-09-23

**선택적 GPU 실행은 구현했지만 이번 DoG 부분 이식에서는 전체 성능이 개선되지
않았다. CPU를 기본으로 유지한다.** 사용법은 [GPU 옵션 문서](GPU_PREPROCESS_ko.md)에 있다.

## 구현 범위

- `MF_PREPROCESS_ACCELERATOR=cpu|auto|gpu`, config의 `accelerator` override.
- Raspberry Pi V3D의 OpenGL ES 3.1 compute, CFA별 Gaussian/DoG 필터.
- 세로/가로 중간 결과 GPU 유지, 버퍼·컨텍스트 재사용, CFA 주기별 shader 특화.
- CPU 전용 모드의 EGL 미로딩, software renderer 거부, auto의 CPU 복귀와
  gpu의 명시적 오류. 초기화·연산·정리는 전용 스레드에서 수행한다.
- `make gpu`, 선택적 라이브러리 패키징, 릴리즈 빌드에 GPU 라이브러리 포함.
  운영 서비스 전환이나 공개 릴리즈 발행은 수행하지 않았다.

GPU C++ 구현도 기존 전처리와 같은 GPL 통합 디렉터리에 둔다.
별 검출기 C ABI, MF4p 알고리즘과 솔빙 정책은 변경하지 않았다.

## 실제 영상 성능

장비는 Raspberry Pi 5 Model B, aarch64, V3D 7.1.7.0이다.
호스트 드라이버는 Mesa 24.2.8이다. 별 검출기는 현재 소스로 전체 재빌드한 MFDS 0.3.2다. 샌드박스 안에서는 `/dev/dri`가 없고
llvmpipe만 표시되어 호스트 GPU 접근이 가능한 실행 환경에서 측정했다.

고정 검증/달·도심 각각 12장씩 2회 재생했다. 배경 작업자 3개, 시간 누적 5장,
포화 4095, MF4p bin4→ROI bin2/sigma4.5/최대128 후보를 공통으로 사용한다.
프레임과 반복마다 CPU/GPU 실행 순서를 교대했다. 각 반복 첫 4장을 제외하여
시간 집계는 장면/방식별 16회다. 영상 디코딩과 비교용 해시·차이 계산은
전처리 타이머 밖이다. 노출·솔빙·UI·마운트는 포함하지 않는다.

단위 ms, 중앙값 / p95:

| 장면 | CPU 전체 전처리 | GPU 전체 전처리 | GPU 중앙값 변화 |
|---|---:|---:|---:|
| 고정 검증 | 1255.0 / 1345.7 | 1374.4 / 1421.5 | **9.5% 느림** |
| 달·도심 | 1218.1 / 1334.4 | 1308.1 / 1427.7 | **7.4% 느림** |

| 장면 | CPU DoG | GPU DoG |
|---|---:|---:|
| 고정 검증 | 178.6 / 219.2 | 272.1 / 286.8 |
| 달·도심 | 170.6 / 217.6 | 269.8 / 294.7 |

DoG 시간은 Python 호출·스레드 전달·GPU 업로드/연산/동기화/다운로드를
포함한 실제 호출 비용이다. 이 비용 중 전송과 커널 각각의 기여를 분리해
측정하지 않았으므로 느린 원인을 전송 하나로 단정하지 않는다. 전처리의
큰 부분인 median/MAD, 연결 성분과 시간 누적은 여전히 CPU에서 실행된다.
공유 메모리를 사용하는 SoC여도 현재 API 경로의 복사와 동기화가 없어지지 않는다.

이전 실행과 절대 시간을 빼서 개선율을 계산하지 않는다. 표는 동일 실행의
CPU/GPU 비교다. 소규모 반복이고 시스템 부하·온도·클럭을 고정하지 않았으므로
p95의 작은 차이를 안정적 개선으로 해석하지 않는다. 정상 RAW foreground의
응답성이나 CPU 사용량·전력 감소도 이번 측정으로 입증하지 않았다.

## 정확도와 검증

실제 영상 비교는 준비 프레임도 포함해 48쌍이다. 픽셀, evidence, MF4p 후보 수,
일대일 할당 후 센서 좌표 차이를 비교한다. 아래 집계와 원본 JSON을 함께 본다.

| 장면 | 최대 출력 픽셀 차이 | 프레임당 변경 픽셀 최대 | 최대 evidence 차이 | 후보 수 불일치 | 최대 좌표 차이 |
|---|---:|---:|---:|---:|---:|
| 고정 검증 24쌍 | 1 ADU | 1개 | 0.001953125 | 0쌍 | 0.0001221 pixel |
| 달·도심 24쌍 | 1 ADU | 4개 | 0.003494263 | 0쌍 | 0.0001221 pixel |

GPU는 float32 계산으로 CPU와 비트 단위 동일하지 않으며, 경계값에서는
float16 양자화·임계값 결과가 달라질 수 있다. 합성 검사는 16-bit 입력,
홀수 크기, 작은 영상, 모서리 별, Bayer 위상별 offset, 핫픽셀, 포화 광원,
희미한 별 시간 누적, reset, 다중 컨텍스트와 호출 스레드를 포함한다.
실제 GPU 테스트에서 GPU 사용 실패를 skip으로 바꾸지 않았다.

- CPU 환경: 24개 통과, 하드웨어 전용 8개는 명시적으로 제외.
- 실제 V3D + GPU 기본 모드: **32개 모두 통과**.
- 기존 native 별 검출 합성 회귀: 현재 소스 전체 재빌드 후 **7/7 통과**.
- CPU 경로와 변경 전 HEAD 비교: 합성 시간 누적 6프레임의 출력/evidence가 픽셀 단위로 동일.
- 별도 snapshot의 ARM64 패키지 생성·버전·전체 파일 SHA256 검사와 패키지 GPU 실기기 실행 통과.
  x86_64 패키지와 GitHub Actions 자체 실행은 이번 로컬 검증에 포함하지 않는다.
- 변경 Python Ruff 검사/포맷, 전처리 mypy, 라이선스·배치 검사 통과.
- 직접 실행한 pytest의 기존 `unit` 마커 미등록 경고 1건은 테스트 실패가 아니다.

최종 별 검출 좌표 비교는 solver의 성공률·카탈로그 잔차·절대 지향 오차를
대신하지 않는다. 라이브 관측과 운영 배포는 검증 범위에 포함하지 않았다.
