# MFDS v0.3.2

RAW 전처리에서 임시 배열과 반복 계산을 줄였습니다. 배경 맵을 제자리 계산하고,
작업 버퍼와 출력 바닥값을 재사용하며 누적 evidence의 상한 처리를 입력 시 수행합니다.
반환 영상은 다음 프레임 처리에서 덮어쓰지 않으며 reset 시 버퍼를 해제합니다.

실제 RAW 22개와 합성·비표준 설정 71개에서 기존 출력 및 진단값의 일치를 확인했습니다.
검출 임계값, 시간 방향 합산 순서, native 검출 알고리즘과 프로세스 ABI는 유지합니다.

Linux ARM64/x86_64 패키지는 Debian Bookworm(glibc 2.36) 환경에서 빌드합니다.
첨부된 SHA-256과 패키지 manifest로 파일 무결성을 확인할 수 있습니다.

PiFinder의 정적 타입 검사에 맞춰 버퍼 크기와 초기화 상태도 명시했습니다.
