# MFDS v0.4.2 — 입력 검증과 이미지 로딩 안정화

RAW16의 폭·높이·행 간격·바이트 수 계산에서 정수 오버플로를 차단합니다.
PGM과 RAW16은 파일 길이를 확인한 뒤 버퍼를 할당하며, PGM 헤더의 크기는
완전한 양의 정수로 검사합니다. 이미지 로딩 실패는 오류로 반환합니다.

검출기 설정의 NaN·무한대와 표현할 수 없는 PSF 크기를 거부합니다.
PSF sigma는 유한한 양수이고 1024 이하여야 하며, 제곱이 0으로 축소되는
값도 사용할 수 없습니다. 기본 검출 설정과 알고리즘은 유지합니다.

새 회귀 테스트는 오버플로 입력, 잘린 이미지, RAW16 행 간격, 8/16비트 PGM,
비정상 PSF 설정을 검사합니다. native 테스트와 sanitizer 검증을 수행하며,
libpng가 없는 빌드도 지원합니다.

Linux ARM64/x86_64, glibc 2.36 이상을 지원합니다. 개발용과 commercial
패키지를 각각 제공합니다. 기존 경로별 라이선스 조건, C ABI 1 및 MFDS1
프로토콜은 유지합니다.
