# MFDS v0.2.0

공개 MFDS의 첫 버전 태그를 갖는 정식 소스 릴리즈입니다. 기존 0.1.0 기반의 최종 검출기·전처리·PiFinder 통합 자료를 포함합니다.

- 포화된 별의 작은 중심과 PSF 주변 광량은 보존하고 넓은 조명·핫픽셀은 제외합니다.
- `VERSION` 하나에서 CLI/서버 `--version`과 C API `mfds_version()`을 생성합니다. ABI 1·MFDS1 프로토콜은 유지합니다.
- PiFinder는 이 릴리즈 커밋을 submodule로 고정해 사용합니다. 실행 파일 이름 `mf_detect_star`는 호환성을 위해 유지합니다.
- 기존 native FSL 5년 MIT 전환 조건, GPL 통합 코드, 과거 MIT 고지를 유지합니다. 버전 태그는 과거 배포분의 권리나 공개일을 갱신하지 않습니다. 경로별 조건은 [LICENSING.md](https://github.com/hjoungjoo/MFDS/blob/v0.2.0/LICENSING.md)를 확인하세요.

## 사용

```bash
git clone --branch v0.2.0 https://github.com/hjoungjoo/MFDS.git
cd MFDS
make -j2
make test
python3 tools/version.py --check-build build --tag v0.2.0
build/mf_detect_star_server --version
```

GitHub 소스 아카이브도 독립 빌드할 수 있습니다. 별도 플랫폼 바이너리나 SD 이미지는 포함하지 않습니다. native 7개 회귀와 프로세스 통합·버전 검사로 검증합니다. 동일 실패 RAW 11장 재생은 0/11에서 11/11로 개선됐습니다. 실제 하늘의 323/323 성공은 PiFinder 전환 수정까지 함께 적용한 결과이며 MFDS 단독 성능 수치로 해석하지 않습니다.
