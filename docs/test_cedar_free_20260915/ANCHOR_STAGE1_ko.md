# 전처리 기준 좌표 실험 — 중간 결과

현재 auto 서비스 경로를 바꾸지 않고 별도 camera-centre 융합 모듈과 비교/replay 도구를 추가했다. RAW 이력과 source frame/노출 epoch가 일치하는 전처리 기준점을3회 확인한 뒤 사용한다. 직접 RAW 차분과 alpha0.3 필터 차분, 누적 구간 평균 reference를 비교했다. 큰 RAW 이동은2회 확인한 뒤 generation/기준점을 reset하고, window의 선형 이동 제거 잔차p95가60″를 넘으면 해당 전처리 기준점을 폐기한다. 단일 큰 RAW 오검출은 보류한다.

119장 기록 중 공통108장의 산포p95: RAW32.65″, 기존bias37.11″, 전처리hold20.09″, 직접차분43.45″, 필터차분22.27″, window평균차분24.09″. 완료지연1.2초/매2프레임 결과를 가정한 좌표재생이다. 단순차분은 RAW잡음을 증폭했으며 필터가 필요하다. RAWdelta방식은 정지 상태를 더 안정적으로 보이게 할 수 있지만 실제 미세 흔들림도 감쇠할 수 있다.

알려진 이동을 넣은 합성좌표: 필터차분의 정답오차 중앙값14.45″/p9542.04″, 큰300″ 이동 반응0.5초. window평균reference는 중앙값11.34″/p9541.08″이지만 실제영상은 산포가 더 커 일괄 적용하지 않는다. 합성전처리는5프레임 단순평균으로 정의했기 때문에 이득이 실제전처리에서 보장되지 않는다.

실제 RAW36장에서는 전처리+MF4→2검출+Tetra3를 별도worker에서 수행하고 전경RAW를 독립 계산했다. RAW36/36, 초기12프레임 RAW 후24프레임 전처리기준+RAW변화량 사용. 전경 중앙값139ms/p95890ms, 배경 중앙값1200ms/p951642ms. 동기 전처리 대기는 없지만 CPU경합과 RAW솔빙 지연은 남는다. 서비스 전체/GOTO 테스트는 아니다.

원본·개별좌표는 로컬 결과에 보관한다. 최종 문서에 지연/누락/흔들림 및 알려진 한계를 확정한다.
