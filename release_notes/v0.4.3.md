# MFDS v0.4.3 — Reliable worker termination regression

The parent-death integration test now accepts `ProcessLookupError` when the
native worker disappears between opening and reading `/proc/<pid>/stat`.
The two-second deadline and failure for a surviving worker are preserved.
This fixes the intermittent MFNavis Nox 3.11 failure observed after m2.6.15.

This release packages the corrected regression for Linux aarch64 and x86_64,
with development and process-only commercial variants. Native detection
algorithms, C ABI 1 and the MFDS1 protocol are unchanged.

## 한국어

부모 프로세스 종료 검사에서 `/proc/<pid>/stat`를 열고 읽는 사이에 worker가
종료되어 발생하는 `ProcessLookupError`를 정상 종료로 처리합니다.
2초 종료 제한과 살아 있는 worker에 대한 실패 검사는 유지합니다.
MFNavis m2.6.15의 Nox 3.11에서 발생한 간헐적 테스트 실패를 수정합니다.

수정된 검사를 포함한 aarch64·x86_64 개발 패키지 및 process-only 판매용
패키지를 제공합니다. 검출 알고리즘·C ABI 1·MFDS1 프로토콜은 유지합니다.

Validation before packaging: 29 real process-boundary integration tests,
30 consecutive parent-death checks and Ruff lint/format passed in the MFNavis
consumer environment. Release CI additionally checks native tests, sanitizers,
the no-libpng build and both architecture packages.
