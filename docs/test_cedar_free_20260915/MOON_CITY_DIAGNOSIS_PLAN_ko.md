# 달 중앙·하단 도심 조명 진단 계획

사용자 조건: 장비 고정, 달이 중앙, 아래쪽에 도심 조명. 현재 운영 소스와 최신 테스트 MF를 구분해 평가한다. 운영 코드/서비스/부팅/노출 설정은 변경하지 않는다.

1. 현재 RAW와 카메라 제어·솔빙 상태를 180회 기록한다. 영상·실제 좌표·장비 설정은 로컬에 보관한다.
2. 포화 영역, 배경 밝기, 후보의 공간 분포와 시간 안정성을 조사한다. 실패 중 남아 있는 과거 좌표를 현재 성공으로 계산하지 않는다.
3. 동일 프레임에서 최신 MF4p와 전처리, MF2/SEP 비교군을 검증한다. 필요하면 달·도시 영역 제외, 하늘 영역 후보 선택, 노출 제어 판단을 독립 실험으로 확인한다.
4. 솔빙 성공과 품질/연속성 검사를 구분하고 RMSE·매칭 수·지연을 집계한다. 지상 조명에 의한 거짓 매칭, 과거 좌표 유지, 밝은 배경 때문에 사라진 별을 각각 구분한다.
5. 재현 자료·관측 제한·개선 우선순위를 결과 문서에 정리한다. 검증하지 않은 노출 증가나 실제 GoTo 성능을 개선 완료로 보고하지 않는다.
