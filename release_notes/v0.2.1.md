# MFDS v0.2.1

MFDS 자체의 라이선스 정책을 명확하게 표시하는 정식 패치 릴리즈입니다.

- native 소스의 SPDX 식별자와 라이선스 파일을 `LicenseRef-MFDS-FSL-1.1-MIT-5year`로 통일했습니다.
- LICENSE 서문, 영문·한글 README, 라이선스 범위와 상용 사용 안내를 MFDS 자체 정책으로 정리했습니다. MFDS 사용 허락은 MFDS의 관련 권리자가 제공합니다.
- 기존 Functional Source License 본문, 5년 후 MIT 전환, 저작권 고지, GPL 통합 코드와 과거 MIT 권한·공개일은 변경하지 않았습니다.
- 검출·전처리 알고리즘, C ABI 1과 MFDS1 프로토콜은 v0.2.0과 동일합니다. 버전 표시는 0.2.1입니다.

[현재 라이선스](https://github.com/hjoungjoo/MFDS/blob/v0.2.1/LICENSE) · [적용 범위](https://github.com/hjoungjoo/MFDS/blob/v0.2.1/LICENSING.md) · [정리 기록](https://github.com/hjoungjoo/MFDS/blob/v0.2.1/docs/LICENSE_IDENTITY_ko.md)

```bash
git clone --branch v0.2.1 https://github.com/hjoungjoo/MFDS.git
cd MFDS
make -j2
make test
python3 tools/version.py --check-build build --tag v0.2.1
```

기존 태그와 최초 이관 해시 기록은 보존합니다. GitHub 자동 소스 아카이브로도 독립 빌드할 수 있으며 별도 플랫폼 바이너리는 제공하지 않습니다.
