# Commercial use / 상용 사용

MFDS is publicly readable source with the existing per-path licenses in
[LICENSING.md](LICENSING.md). It is not offered as a blanket permissive license.

- Native MF code uses `LicenseRef-MFDS-FSL-1.1-MIT-5year`, as written in
  [LICENSE](LICENSE). Competing Use is outside the Permitted Purpose grant.
  Obtain separate permission from the relevant MF rightsholders before
  distributing a product or service outside that grant. Requests can be directed
  to the MFDS repository maintainers; making a request does not grant permission.
- The LICENSE permits uses that meet its Permitted Purpose definition, including
  internal use. This page does not newly require approval for uses already granted.
- Each covered version receives its future MIT grant on the fifth anniversary
  specified by its publication. A new release or repository migration does not
  extend an earlier version's deadline or revoke earlier MIT grants.
- PiFinder-derived integration, preprocessing code and imported experiment
  records retain GPL-3.0. No native commercial restriction is added to those files.
- Existing third-party notices and legacy MIT rights are preserved. A permission
  from MF rightsholders does not waive another project's license requirements.

한국어: MF native의 경쟁 제품·서비스 제공 등 현재 FSL 허락 범위를 벗어나는
상용 배포에는 별도 허락이 필요하다. 저장소 공개만으로 그 허락이 생기지 않는다.
현재 FSL의 허용 목적과 버전별 5년 뒤 MIT 전환은 유지하며, 모든 유료 제품에
영구적인 사전 승인을 요구하는 새 문구를 추가한 것은 아니다.
PiFinder에서 유래한 GPL 부분에는 MF 상용 제한을 붙이지 않는다.
이 안내와 이관은 새 라이선스 계약이나 결합 배포에 대한 법률적 판정이 아니다.
