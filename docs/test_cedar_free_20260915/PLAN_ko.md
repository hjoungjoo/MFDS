## 단계

1. 운영 상태 기록, 소스 복제, 테스트 브랜치 생성, 계획 커밋·푸시.
2. 현재 고정 장면 RAW와 프레임/노출/게인/솔버 상태를 수집한다. 기존 9월 3일 광해 30장과 구름 120장도 비교에 사용한다. 원본 데이터는 로컬 보관하고 manifest/hash와 집계 결과를 문서화한다.
3. 테스트 소스에서 Cedar Detect 실행·번들 의존성을 제거하고 SEP+시간 전처리의 중앙→전체 솔브를 검증한다. 같은 좌표 변환, 보정, 품질 게이트를 유지한다.
4. 자체 검출기를 같은 전처리·솔버 계약에 연결한다. 별 후보 수가 아닌 솔브율, 매치 수, RMSE, 고정 장비 좌표 산포와 오솔브로 평가한다. 기존 전처리 출력의 정합 결과는 비교 기준이며 독립 절대 위치 정답은 아니다.
5. 품질을 유지하는 범위에서 프로파일링, 비닝/원해상도 centroid, 버퍼·필터 최적화를 진행한다. 검출/전처리/솔브/총지연을 구분하며 최신 프레임, 이동 시 누적 초기화와 GOTO freshness 계약을 보존한다.
6. 관련 테스트·lint/format/type/smoke를 수행하고 각 단계 결과와 한계를 기록해 푸시한다. 운영 소스/부팅 서비스 불변을 마지막에 확인한다.
