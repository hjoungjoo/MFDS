# 전처리 기준 좌표 + RAW 변화량 — 작업 전 계획

새 사용자 요청을 위한 별도 실험이다. 현재 검증된 auto/동기 복구 서비스 경로와 기본 설정은 유지한다. 실험은 전처리+검출+Tetra3 솔빙을 모두 별도 worker에서 항상 수행하고, RAW 좌표는 독립 계산한다. 전처리 좌표가 연속 안정화되기 전에는 RAW를 사용하고 이후에는 전처리 기준점에 같은 촬영시각부터의 RAW 변화량을 더한다.

중요한 가설: P(t_anchor)+[R(t_now)-R(t_anchor)]는 응답성이 좋지만 RAW의 두 시점 잡음을 그대로 끌어온다. 기존 bias 방식과 단순히 수학적 표현만 달라질 수도 있다. 따라서 직접 변화량/필터한 변화량/전처리 결과 그대로 유지/기존 RAW+bias를 비교한다. RMSE가 작다는 사실만으로 절대 정확도 우위를 전제하지 않는다.

구현 범위는 카메라 중심 RA/Dec 실험 모듈과 재현 harness다. RA wrap/극점은 구면 벡터로 처리하고 촬영시각·frame id·generation·기준점 유효기간·RAW 누락을 보존한다. 전체 마운트/GOTO 제어에 연결하지 않는다. 이미지 Roll/정렬된 target pixel과 IMU 센서 융합은 이번 중심좌표 실험에서 검증되지 않는다.

실험1: 동일 영상의 기존 RAW/전처리 검출 결과를 실제 기록 경과시간으로 재생하며 완료 지연1.2초/2.5초를 부여해 산포·좌표게시 지연·유효 비율을 비교한다. 입력마다 이미 안정적인 전체 전처리 캐시를 사용한 optimistic 비교이므로 비동기 skip 효과는 별도검증한다.

실험2: 알려진 정답의 좌표 궤적에 드리프트/계단 이동/흔들림/RAW 오검출/누락/뒤늦은 결과를 넣어 위치오차와 이동 반응시간을 측정한다. 움직임 중 시간 누적 영상은 오염될 수 있어 RAW 이력에서 흔들림을 감지하면 오래된 전처리 기준점과 해당 누적창을 폐기하는 정책을 시험한다. 소프트웨어만으로 노출 중 블러를 복원했다고 주장하지 않는다.

실험3: 녹화 RAW에 실제전처리3-worker, 동일 MF4→2 검출, 별도Tetra3를 사용해 전경 RAW 계산이 background 처리 완료를 기다리지 않는지 확인한다. 같은 frame id/시간의 대응을 검사하고 일부 결과를 건너뛰는 bounded queue를 유지한다.

단계별 계획/소스/집계를 기존 승인된 두 테스트 브랜치에 푸시한다. 원본·개별 좌표는 로컬 보관하며 운영 서비스/카메라/부팅은 변경하지 않는다.
