# 속도 개선 및 재검증 계획

2026-09-15. Cedar 비교에서 구름 RAW는 MF 후보 약12개로 솔빙에 중앙값
1.17초를 쓰지만 성공하지 못했다. 정상 RAW에도 1초 가까이 걸려 성공하는
사례가 있어 시간 제한 단축이나 후보 일괄 제거는 우선 적용하지 않는다.

1. 기록 영상으로 검출·Tetra3 검색을 프로파일링한다. 반복 계산과 자료 변환을
   먼저 줄이고 후보 순서, 검색 범위, 품질 기준, 1000ms 제한을 유지한다.
2. 개발 자료(구름 앞16장, 고정 광해 current)로 개선 전후를 확인한다.
3. 검증 광해119장과 구름 후속 자료의 RAW/전처리를 같은 검출기와 기하로
   재생한다. 성공률, 매칭 수, RMSE, 중앙값/p95, SEP 보조 횟수를 기록한다.
4. 병렬 전처리 실제 스케줄러 재생, native/Python 전체 관련 테스트와 정적
   검사를 실행한다. RAW 실패·정렬·보정의 동일 프레임 대기를 유지한다.
5. 적용 코드와 집계 결과를 두 승인된 테스트 브랜치에 푸시한다. 운영 소스,
   서비스, 부팅 설정은 변경하지 않는다. 원본과 상세 좌표는 로컬에 보관한다.

실측은 고정 장비 기록 재생이다. 미연결 마운트의 GOTO 동작이나 새로운
실시간 하늘 관측의 성능을 검증했다고 주장하지 않는다.
