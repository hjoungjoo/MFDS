# 전처리 실행 위치와 중복 계산 비교 계획

2026-09-15. 기준 MF `7bcefb9`, PiFinder `248d85bf`.

목적은 MF 쪽으로 전처리를 모을 때 계산 시간과 RAW 응답성이 개선되는지
실측하는 것이다. 운영 서비스, 부팅 설정, 카메라, 마운드는 변경하지 않는다.

비교는 같은 RAW, 전처리 설정(배경 스케일 작업자 3개, 시간 창 5장), MF4p로 한다.

1. 현재 구조: 호출 프로세스의 전처리 + 별도 native MF 검출 프로세스.
2. 위치만 분리: 공유 메모리 시험 프로세스에서 같은 전처리 + 별도 native MF.
3. 합친 계산의 성능 모형: 시험 프로세스에서 같은 전처리 + MF ctypes 비교 경로.
4. 중복 제거 모형: 3번에 과거 프레임의 단일 별 후보 마스크 캐시를 추가.

3/4번은 기존 명시적 ctypes 비교 기능을 사용한 내부 실험이다. GPL 전처리를
FSL native 실행 파일에 넣거나 재라이선스하지 않는다. C++ 포팅이나 상용 배포의
라이선스 적합성을 입증하는 실험도 아니다. 실행 위치와 검출 IPC 제거 효과를
분리해 측정하는 근사 모형이며 최종 구현의 성능을 보장하지 않는다.

먼저 실측 프로파일을 확인했다. 검증 데이터 6장 전처리 합계 6.324초 중
별 후보 형태 분류가 0.841초였다. 스레드 내부 시간은 이 프로파일에 직접
포함되지 않으므로 배경 스케일 계산의 세부 시간으로 해석하지 않는다.

검증/구름 기록 각각 연속 프레임을 사용하고 순서를 교대한다. 준비·프로세스
시작 시간과 지속 처리 시간을 구분한다. 전처리 영상/별 좌표/밝기를 정확히
비교하고, 전처리+검출+솔빙 p50/p95, 성공률, RMSE를 기록한다. RAW 검출을
동시에 반복하는 추가 시험으로 경합 시 지연도 확인한다. 이는 실제 카메라,
정렬 상태기계, 마운드 GOTO 시험을 대체하지 않는다.

원본 영상/관측 좌표는 로컬에 유지하며 집계 결과와 재현 도구만 푸시한다.
