# 토성 GoTo/추적 검증 계획

사용자가 토성 GoTo 중 테스트를 요청했다. 이동 상태는 즉시 보존하고 분석 전에
이 계획을 정리한다. 기록 시작 시 큰 이동은 끝났고 마운트는 추적 상태였다.
초기 이동·반복 보정은 남은 운영 로그로, 현재 추적 안정성은 새 기록으로 확인한다.

- 기존 운영 PiFinder/Cedar를 유지한다. 노출·gain·GoTo·Sync·guide 명령을 보내지 않는다.
- RAW 출력이 꺼져 있어 기록 출력만 임시 활성화하고 240장/약 120초를 수집한 뒤
  원래 비활성 상태로 복원한다. 기록 출력 부하를 포함한 실측이라는 한계를 남긴다.
- 마운트/IMU/솔빙과 별도 GoTo·guide 상태를 기록한다. 목표 좌표는 실제 제어기의
  target에서 가져오고 기록 시각·출처·정렬된 관측 축/카메라 축을 구분한다.
- 기록 시작 전 이동 로그와 기록 중 추적 오차·솔빙 간격·품질·보정 상태를 분석한다.
- 같은 저장 영상에 MF4p/MF2의 RAW/전처리를 재생한다. 이전 달·도심 수동 마스크는
  새 장면에 적용하지 않는다. 운영 Cedar와 재생 MF의 환경/스케줄 차이를 명시한다.
- 실제 이동 구간 RAW를 놓쳤다면 현재 자료로 이동 중 보정 효과를 입증했다고
  주장하지 않는다. 원본·좌표·설정은 로컬, 코드·문서·집계만 승인된 테스트 브랜치에 푸시한다.
