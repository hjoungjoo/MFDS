# 다단계 해상도/ROI 검출 실험 — 작업 전 계획

사용자 아이디어: 전체 저해상도에서 별 후보를 찾고, 해당 후보 주변의 작은 영역(ROI)을 단계적으로 높은 해상도에서 확인한다. 광학 화각/노출을 변경하지 않고 같은 프레임에서 계산 영역만 줄인다. 각 ROI 좌표를 원본 전체 센서 좌표로 복원해 기존 솔버 기하를 유지한다.

기존 native 검출은 이미 전체 2×2 축소 영상을 사용한다. 이번 실험은 전체 4×4(필요 시8×8) → 후보별64×64 원본 영역의2×2 검출 → 선택적으로32×32 원본 검출이다. 후보가 저해상도에서 사라지면 후속 정밀화로 복구할 수 없고, ROI별 배경 차이/별 밀집/경계도 오차 원인이므로 성공률과 RMSE를 함께 확인한다. 후보 검출 실패 시의 자동 전체 탐색 재시도는 이번 실험에 추가하지 않아 비용과 실패를 그대로 측정한다.

비교: 기존 MF2, SEP, MF4→2 ROI, MF4→2→1 ROI. 개발은 current 첫30장, 후속 평가는 독립validation119장과 과거cloud 평가102장으로 고정한다. 동일 전처리 캐시/기하/품질 게이트, 실행순서 교대, 운영 서비스는 유지하고 다른 무거운 실험은 동시에 실행하지 않는다. 단일 검출 시간과 검출+솔브 시간, RMSE, 성공수, 매칭수, 좌표 산포를 보고한다. 전체 처리의 큰 비중인 약1.7초 전처리는 이번 실험에서 공통이며 검출 개선을 전체 속도 개선과 혼동하지 않는다.

합성 별 좌표, 핫픽셀, 경계/비연속stride 및 중복 후보를 검사한다. 소스와 집계만 기존 승인된 두 테스트 브랜치에 단계적으로 푸시한다. 운영 서비스/설정/부팅과 기본 backend는 변경하지 않는다.
