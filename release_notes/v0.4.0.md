# MFDS v0.4.0

라즈베리 파이 4·5에서 사용할 수 있는 NEON 시간 누적 최적화와 선택적 GPU
전처리를 추가했습니다. 기본 구성은 **CPU DoG + 사용 가능한 NEON 누적**입니다.
검출 임계값, float16 왕복 양자화, 프레임 간 FP32 합산 순서, native detector
C ABI 1과 MFDS1 프로세스 프로토콜을 유지합니다.

## 옵션과 호환성

- `MF_PREPROCESS_REDUCTION=auto|numpy|neon`: 기본값 `auto`는 ARM64 Linux의
  CPU 기능과 라이브러리 ABI를 확인해 NEON을 사용합니다. 사용할 수 없거나
  지원하지 않는 설정이면 NumPy로 복귀합니다. `numpy`는 기존 누적을 강제하고,
  검증용 `neon`은 실행 실패를 예외로 보고합니다.
- NEON 라이브러리는 파이 4 Cortex-A72와 파이 5 Cortex-A76의 공통 ARMv8-A
  명령으로 빌드합니다. 파이 5 전용 컴파일 설정은 추가 성능 이득이 없어
  채택하지 않았습니다. 비 ARM 환경은 NumPy 경로를 사용합니다.
- `MF_PREPROCESS_ACCELERATOR=cpu|auto|gpu`: DoG 필터의 독립적인 GPU 실험
  옵션입니다. 기본값은 `cpu`입니다. `auto`는 V3D 사용을 시도하고 실패 시 CPU로
  복귀하며, 속도를 측정해 자동 선택하는 옵션은 아닙니다. 현재 실측 GPU 경로는
  CPU보다 느립니다. GPU 사용 시 EGL/GLES 런타임과 DRM 장치 접근이 필요합니다.

## 실측과 검증

파이 5에서 1920×1080 실영상, 배경 worker 3개, 누적 5장으로 비교했습니다.
영상 묶음별 12장×2회 실행하고 각 반복 첫 4장을 시간 집계에서 제외했습니다.

| 영상 묶음 | NumPy 전체 전처리 중앙값 | NEON 전체 전처리 중앙값 | 감소 |
|---|---:|---:|---:|
| 고정 검증 | 1,395.0 ms | 1,240.3 ms | 11.1% |
| 달·도시 | 1,339.3 ms | 1,252.4 ms | 6.5% |

준비 프레임을 포함한 48쌍에서 출력 픽셀·evidence·진단값이 정확히 일치했습니다.
전체 솔빙·노출·UI 시간은 포함하지 않습니다. 파이 4에서는 Cortex-A72 에뮬레이션
검증을 통과했으며, 실기기 동작·성능은 아직 측정하지 않았습니다.

누적/전처리 Python 77개와 실제 V3D GPU/전처리 32개 테스트를 통과했습니다
(전처리 20개 중복). native detector 7개와 NEON 누적 35개, 미지원 라이브러리
복귀, NumPy 강제 실행, 패키지에서의 자동 선택·라이브러리 부재 복귀도 검증했습니다.

## 배포

Linux aarch64 및 x86_64 패키지를 Debian Bookworm에서 빌드하며 glibc 2.36 이상을
대상으로 합니다. 패키지는 서버·CLI·공유 라이브러리, 전처리 helper, GPL Python
연동 코드·검증 도구·문서·라이선스 고지 및 파일별 SHA-256 manifest를 포함합니다.
첨부된 `.sha256` 파일로 압축 파일의 무결성을 확인할 수 있습니다.

PiFinder 운영 반영에는 새 MFDS 버전·소스 커밋·패키지 체크섬 고정이 별도로 필요합니다.
소스와 C++ helper 구현은 이 릴리즈 태그에서 제공합니다.
