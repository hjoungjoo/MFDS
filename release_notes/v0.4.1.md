# MFDS v0.4.1 — 작은 별 수정 및 배포 프로필 추가

일반 개발 패키지와 별도로 `-commercial` 패키지를 제공합니다. 상용 프로필은
독립 worker만 포함하고 native 로더·공유 라이브러리를 제외하며 CPU/NumPy
전처리를 사용합니다. MFNavis 제품의 제작·배포 주체 표기도 정리했습니다.
기존 경로별 라이선스 조건은 유지됩니다.

4×4 축소 후 한 픽셀이나 얇은 두 픽셀에 모인 작은 별이 초기 크기·모양
검사에서 탈락하는 문제를 수정했습니다. 기존 전체 4×4 탐색 → 후보 주변
2×2 정밀화는 그대로 유지합니다. 최종 잡음 제거 조건, 검출 임계값,
PSF 커널과 후보 수 상한은 변경하지 않았습니다.

표시용 `overlay_max_stars` 요청을 반영해 품질 필터를 통과한 후보를 별도로
반환합니다. 솔버 입력은 기본 48개로 유지하며 추가 탐색을 수행하지 않습니다.

검증: native 8개, temporal reduction 35개 창, 관련 Python/소비자 테스트
98개 통과. 저장 RAW 40장에서 기존 후보 1,936개를 모두 유지하고 후보 12개를
추가 검출했습니다. 검출 시간 중앙값은 44.12 → 42.56 ms로 이 자료에서는
속도 저하가 관찰되지 않았습니다. 추가 후보의 카탈로그 매칭과 현재 8 mm
촬영 원본 RAW 검증은 남아 있습니다.

Linux ARM64/x86_64, glibc 2.36 이상. C ABI 1 및 MFDS1 프로토콜은 유지됩니다.
