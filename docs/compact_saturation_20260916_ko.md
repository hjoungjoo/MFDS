# 포화 별 보존 수정 — 2026-09-16

맑은 하늘에서 밝은 별의 중심까지 조명으로 제외하던 포화 규칙을 수정했다. 원본 센서 좌표의 8연결 영역이 96픽셀 이하이고 가로세로가 16픽셀 이하일 때 주변 PSF 광량을 확인해 보존한다. 중심 바깥 1·2픽셀 테두리와 4·5픽셀 테두리의 평균을 비교해 Bayer 위상에 따른 오판을 줄인다. 확장된 포화 영역, 주변 광량 없는 점과 사각형은 기존 팽창 마스크로 제외한다.

MF Python 어댑터의 중복 peak-only 제외를 제거했고 SEP 보조에는 같은 작은 중심 판정을 적용했다. 검출기와 어댑터를 같은 커밋으로 빌드해서 사용해야 한다. 전처리와 라이선스 정책은 변경하지 않았다.

## 검증

- 이전 실패 RAW 11장: 기존 0/11 → 수정 11/11. 검출+패턴 솔빙 중앙값 2,045.7 → 60.6ms, 수정 RAW RMSE 중앙값 20.99초각. 저장 영상 재생으로 노출·게시 지연은 포함하지 않는다.
- 달/도심 RAW 6장과 전처리 6장: 기존·수정 모두 미솔빙. 구름 전처리 6장: 기존·수정 모두 5/6 성공. 전처리 12장의 검출 좌표는 완전히 동일했다. 표본 내 회귀가 없다는 뜻이며 모든 조명을 구분한다는 보장은 아니다.
- native 7/7: 포화 별/사각 조명/핫픽셀, binning 1·2·4, 피라미드와 패딩 stride 포함.
- Python 관련 회귀 102개 통과. ASan/UBSan 및 누수 검사 7/7 통과. 로컬 ptrace 제한이 있어 누수 검사는 호스트에서 재실행했다.

원본 영상과 장비별 좌표·설정은 비공개 로컬 검증 자료로 보관한다. 앱의 프레임 원자 전달 및 운영 검증은 MF_PiFinder의 `docs/mf_report/mf_compact_saturation_frame_pair_fix_20260916_ko.md`에 기록한다.
