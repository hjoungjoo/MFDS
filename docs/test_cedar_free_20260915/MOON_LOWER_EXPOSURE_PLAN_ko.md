# 중앙 하단 달/도심 장면 노출 비교 계획

사용자가 장비 방향을 변경한 뒤 현재 장면 기록과 노출 변경 실측을 요청했다.
이전 중앙 달 장면과 다른 corpus로 보존한다. 마운트는 연결하지 않는다.

1. 현재 자동 노출에서 RAW 40장을 기록한다.
2. gain 30에서 25/50/100/200/400 ms를 비교한다. 추가로 200 ms/gain 15,
   400 ms/gain 8, 마지막 100 ms/gain 30 재측정을 각 32장 기록한다.
   앞의 고정 gain 실험으로 노출 효과를, 추가 실험으로 비슷한 광량에서 gain
   감소 효과를 살핀다. 요청값과 센서 실제값을 구분하고 안정화 후 수집한다.
3. 성공/예외 시 원래 노출·gain 모드를 복원하고 자동 노출 40장을 다시 기록한다.
4. 동일 RAW를 MF 기본 검출 + 전처리 window 5/10으로 재생한다. 새 장면을
   확인한 별도 수동 마스크와 마스크 없는 결과를 비교한다. SEP는 기존 MF
   fallback 정책만 사용한다. 전처리 이력은 노출 조건 사이에서 초기화한다.
5. 포화, 배경, 후보 수, 품질 기준 통과율, RMSE, 처리 시간을 집계한다.
   시간 순서에 따른 하늘 변화와 겹치는 누적 프레임의 비독립성을 명시한다.

원본 TIFF, SHA256, 촬영 전후 설정, 관측 좌표 API 응답, 센서 메타데이터,
실험 요청/적용 기록은 PiFinder_test_data에 로컬 보관한다. 확정된 타겟 좌표가
없으면 만들어 넣지 않는다. API 좌표는 TIFF와 원자적으로 결합되지 않는다.
서비스/부팅 경로와 운영 소스는 변경하지 않는다. 코드·문서·집계만 승인된
두 저장소 test/cedar-free-20260915 브랜치에 푸시한다.

## 촬영 후 장면 변화

노출 변경과 전후 기준 촬영을 마친 후 사용자가 달이 완전히 사라졌다고 알렸다.
이후 자동 노출 RAW 40장을 별도 corpus로 기록하며 달이 보이던 336장과 합쳐
노출 성공률을 계산하지 않는다. 달이 사라진 원인은 확인되지 않았다.
처음 100 ms와 마지막 100 ms 재측정 차이도 함께 보고하여 촬영 순서/하늘 변화의
영향을 명시한다. 누적 창 비교는 같은 저장 영상으로 수행한다. 달이 보이지 않는
자료는 달 원형 마스크를 끄고 지상 영역 제외만 별도 비교한다.
